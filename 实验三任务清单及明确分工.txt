【选题背景】
  参照实验一"面向早教需求的手写数字识别"思路，结合语音识别与智能评测技术，
  设计一款面向幼儿/小学生的英语口语发音训练系统。该系统能够：
    - 识别用户朗读的英文字母（A-Z，26类）和基础英语单词
    - 对发音准确度进行智能打分（0-100分）
    - 播报标准发音，帮助用户纠正发音
    - 提供友好的图形界面（录音→识别→评分→反馈→学习闭环）

  选题依据：
    - PPT实验3明确提到"面向早教需求"的示例，体现智能技术的教育应用
    - 符合《机器智能》第七章"机器智能的应用"要求
    - 语音识别+智能评测具有明确的创新性和实际应用价值
    - 覆盖语音信号处理、神经网络分类、人机交互等多个技术点

【核心功能模块】

  模块一：语音采集与预处理
    - 麦克风实时录音（wav格式，16kHz采样率）
    - 音频预处理：降采样、归一化、VAD语音活动检测去静音
    - 分帧、加窗（汉明窗）

  模块二：语音特征提取
    - MFCC（梅尔频率倒谱系数）提取13-40维特征
    - 含一阶差分（Delta）和二阶差分（Delta-Delta）
    - 帧级特征聚合为固定长度特征向量（取均值+标准差）

  模块三：发音识别与评测（核心智能模块）
    - BP神经网络分类器：识别用户读的是哪个字母/单词
    - 发音打分算法：结合分类置信度 + DTW对齐距离 + 声学相似度综合评分
    - 标准发音模板库：预存标准美式/英式发音的MFCC特征作为参考

  模块四：标准发音反馈
    - 预录制标准发音音频（或使用TTS引擎生成）
    - 用户识别错误或分数低时，自动播放标准发音
    - 显示发音对比波形图 / MFCC频谱对比图

  模块五：图形用户界面（GUI）
    - 模式选择：[字母模式] [单词模式]
    - 录音按钮 + 实时波形显示
    - 识别结果 + 评分显示（圆形进度条/星级评分）
    - 正确发音按钮（播放标准音）
    - 历史记录 + 学习进度追踪

  模块六：对比实验与评测
    - BP vs CNN/RNN 模型对比（准确率、速度）
    - 不同MFCC维度对比（13维/26维/40维）
    - DTW距离 vs 置信度打分方案对比
    - 不同信噪比下的鲁棒性测试

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
成员A：语音数据采集 + MFCC特征提取 + 数据增强 + 标准发音库
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
任务描述：

  1. 语音数据采集（字母A-Z + 基础单词）
     - 字母数据集：小组成员每人朗读A-Z各10-20遍，共约780-1560条音频
     - 单词数据集：选取50-100个基础英语单词（cat, dog, apple, book等）
       小组成员每人朗读每个单词5-10遍
     - 使用公开数据集作为补充：
       · Google Speech Commands 数据集
       · Free Spoken Digit Dataset (FSDD) 可参考其格式
       · CMU Kids Corpus（儿童语音数据，与早教场景匹配）
     - 统一录音规范：16kHz采样率、16bit、单声道、wav格式

  2. 音频预处理流水线
     - 重采样至16kHz
     - 幅度归一化（归一化到[-1, 1]）
     - VAD（语音活动检测）：使用短时能量+过零率双阈值法去除首尾静音
     - 预加重滤波（pre-emphasis，系数0.97）
     - 分帧（帧长25ms，帧移10ms）
     - 加窗（汉明窗 / Hamming Window）

  3. MFCC特征提取实现（核心）
     a) 对每帧计算FFT（快速傅里叶变换）得到功率谱
     b) 应用Mel滤波器组（26-40个三角滤波器）
     c) 取对数能量
     d) 计算DCT（离散余弦变换）得到MFCC系数（13-40维可选）
     e) 计算一阶差分（Delta MFCC）和二阶差分（Delta-Delta MFCC）
     f) 帧级特征聚合为固定长度向量：
        - 对每维MFCC取均值 + 标准差
        - 最终特征向量维度 = MFCC维数 × 3（静态+Δ+ΔΔ）× 2（均值+标准差）
        - 例：13维MFCC → 13×3×2 = 78维特征向量

  4. 标准发音模板库构建
     - 从公开资源获取标准美式/英式发音音频（字母+单词）
     - 或使用高质量TTS引擎生成（pyttsx3 / gTTS / Azure TTS）
     - 提取每个标准发音的MFCC特征作为"金标准"参考模板
     - 存储为 templates.json 或 templates.pkl

  5. 音频数据增强（提升泛化能力）
     - 添加高斯白噪声（不同信噪比：10dB, 15dB, 20dB, 30dB）
     - 时间拉伸（speed：0.9x ~ 1.1x）
     - 音调微调（pitch shifting：±2半音）
     - 音量随机缩放（±3dB）
     - 使训练数据扩充3-5倍

  6. 数据集划分与组织
     - 字母识别：训练集60%、验证集20%、测试集20%
     - 单词识别：训练集60%、验证集20%、测试集20%
     - 确保同一说话人的音频不出现在训练和测试中（说话人独立划分）
     - 输出统一格式：audio_path + label + features（.npy / .csv）

  7. 编写模块文件
     - audio_collector.py    ：录音采集工具
     - audio_preprocess.py   ：音频预处理管线
     - audio_feature.py      ：MFCC特征提取
     - data_augmentation.py  ：音频数据增强
     - template_builder.py   ：标准发音模板构建
     - prepare_data.py       ：数据集准备与划分入口

  预计工作量占比：33%

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
成员B：BP神经网络核心 + 发音评测算法 + CNN/RNN对比模型 + 评价指标
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
任务描述：

  1. BP神经网络类实现（从零手写，不调用现有NN框架）
     - 网络结构：
       · 输入层：维度由成员A的MFCC特征向量维度决定（如78/156/234维）
       · 隐含层：1-2层，神经元数可配置（如256-128 或 128-64）
       · 输出层：
         - 字母模式：26个神经元（A-Z，Softmax输出）
         - 单词模式：N个神经元（N=单词数，Softmax输出）
     - 激活函数：支持 Sigmoid / ReLU / Tanh 切换及对比
     - 输出层：Softmax + 交叉熵损失（Cross-Entropy Loss）

  2. 训练优化模块
     - 小批量梯度下降（Mini-batch SGD）
     - 动量项（Momentum，β=0.9）加速收敛
     - 自适应学习率衰减（阶梯衰减 + 指数衰减可选）
     - L2正则化（权重衰减系数可调）
     - Dropout（0.2-0.5）防止过拟合
     - Early Stopping（基于验证集loss，耐心值=15-20轮）
     - Xavier / He 权重初始化
     - 模型保存与加载（.npy格式保存权重矩阵）

  3. 发音智能评测打分模块 ★核心创新★
     综合三种打分策略，加权融合得出最终评分（0-100分）：

     a) 置信度打分（权重40%）
        - 取BP网络Softmax输出中目标类的概率值
        - 概率越高→发音越标准→分越高
        - 公式：score_conf = softmax_prob(target_class) × 100

     b) DTW对齐距离打分（权重35%）★创新★
        - 使用DTW（动态时间规整）算法对齐用户MFCC序列与标准模板MFCC序列
        - 计算对齐后的平均欧氏距离
        - 距离越小→发音越接近标准→分越高
        - 公式：score_dtw = max(0, 100 - α × dtw_distance)
        - α为缩放系数，通过实验数据校准

     c) 声学特征相似度打分（权重25%）★创新★
        - 比较用户发音与标准发音的基频(F0)轮廓相似度
        - 比较共振峰(formant)频率差异
        - 比较短时能量包络的相似度
        - 综合三个声学维度的余弦相似度
        - 公式：score_acoustic = cosine_sim(user_vector, template_vector) × 100

     最终得分 = 0.4×score_conf + 0.35×score_dtw + 0.25×score_acoustic

  4. 评价指标模块
     - 分类指标（字母/单词识别）：
       · 各类别 Precision / Recall / F1-score
       · 整体 Accuracy / Macro-Avg / Micro-Avg
       · 混淆矩阵（字母26×26、单词N×N）
     - 评分算法评测：
       · 评分与人工专家评分的皮尔逊相关系数（Pearson r）
       · 平均绝对误差（MAE）
       · 均方根误差（RMSE）
     - 可视化输出：
       · 混淆矩阵热力图（Matplotlib + Seaborn）
       · 训练Loss/Accuracy曲线
       · 不同打分策略权重对比柱状图

  5. CNN/RNN对比模型（使用PyTorch）
     - CNN模型：1D-CNN处理MFCC时间序列特征
       · 2-3层卷积 + 池化 + 全连接
       · 不将帧特征聚合，直接输入MFCC时间序列（帧数×MFCC维度）
     - RNN/LSTM模型（可选扩展，有余力时做）
       · 双向LSTM + 全连接分类层
     - 对比实验设计（统一数据集，统一训练/测试划分）：
       · 准确率对比：BP vs CNN vs (LSTM)
       · 训练/推理时间对比
       · 模型参数量对比
       · 不同信噪比下的鲁棒性对比
       · 表格+柱状图+雷达图多维度可视化

  6. 超参数调优实验
     - 对比不同MFCC维数（13/26/40）对识别率的影响
     - 对比不同隐含层结构（单层128 vs 双层256-128 vs 双层128-64）
     - 对比不同激活函数的效果
     - 对比不同学习率（0.1, 0.01, 0.001, 0.0001）的收敛曲线
     - 对比有无数据增强对泛化能力的影响

  7. 编写模块文件
     - bp_network.py       ：BP神经网络核心类
     - train.py            ：训练流程（字母/单词）
     - pronunciation_scorer.py ：发音打分模块 ★
     - dtw_matcher.py      ：DTW对齐匹配算法 ★
     - cnn_model.py        ：CNN模型（对比用）
     - rnn_model.py        ：RNN/LSTM模型（可选）
     - metrics.py          ：评价指标+混淆矩阵
     - hyperparam_tuning.py：超参数调优实验脚本

  预计工作量占比：34%（算法核心+打分创新+模型对比，技术含量最高）

【模块接口约定（关键！确保联调顺利）】

  1. 成员A → 成员B 的接口（特征数据）：
     - 函数：extract_features(audio_path: str) → np.ndarray (shape: [feature_dim])
     - 函数：extract_sequence_features(audio_path: str) → np.ndarray (shape: [n_frames, n_mfcc])
       （序列特征用于DTW和CNN）
     - 函数：load_dataset(data_dir: str) → (X_train, y_train, X_val, y_val, X_test, y_test)
     - 数据格式：X为np.float32，y为np.int32（类别索引）
     - 标签映射文件：label_map.json（如 {"A": 0, "B": 1, ...}）

  2. 成员B → 成员C 的接口（模型调用）：
     - 类：BPNetwork(model_path: str) → predict(features: np.ndarray) → dict
       返回：{"class": str, "confidence": float, "probs": np.ndarray}
     - 类：PronunciationScorer() → score(user_audio, template_audio) → dict
       返回：{"total_score": float, "conf_score": float, "dtw_score": float, "acoustic_score": float}
     - 类：CNNModel(model_path: str) → predict(sequence_features: np.ndarray) → dict
       返回：同上

  3. 成员C GUI 调用的统一入口（main.py流程）：
     audio → [成员A] audio_preprocess + audio_feature → features
           → [成员B] bp_network.predict(features) + pronunciation_scorer.score(audio, template)
           → [成员C] gui.display_result(result, score)
           → [成员C] tts_player.play(template_audio)  # 标准发音
